# claude-ops-portfolio

Claude Code（Anthropic の CLI（コマンドライン）ツール）を自律運用するための、コスト・安全・記憶を制御するハーネス（実行基盤）である。
2026 年 1 月から現在まで、日常の開発・運用作業のすべてをこの基盤の上で回している。
規模: 8 プロバイダへの直 API 振り分け層（`scripts/ask.py`、1,228 行）、破壊操作・課金・機密送信を止める hook（実行前後の自動介入）6 本（453 行）、記憶（memory）66 件（うち失敗から得た恒久ルール 33 件）、サブエージェント 6 体で構成する。
2026-07-09 の実インシデントを起点に hook 化した改修サイクルを持ち、事故対応から鍛えられた基盤である。
この基盤の上で、注文約 1,000 件を処理してきた本番システムの開発・運用も行っている（詳細は職務経歴書）。

実装は AI（Claude Code）に委譲し、要件定義・アーキテクチャ設計・コードレビュー・動作検証・本番運用を担当している。
本リポジトリには、実運用中の環境から再利用可能な設計部分だけを抜粋している（実データ・実運用の memory・settings.json の実値は含まない）。

## アーキテクチャ

```
利用者
  └→ Claude Code（エージェント実行基盤）
       ├→ 振り分け層   scripts/ask.py（1,228 行）
       │    用途と機密度に応じて、中間業者を挟まずに 8 社の直 API
       │    （Anthropic / OpenAI / Google / xAI / DeepSeek / Moonshot / Zhipu 等）
       │    + ローカル Ollama を alias 一発で呼び分ける
       │
       ├→ 委譲層       agents/*.md + skills/*
       │    サブエージェント 6 体（要約=軽量モデル / 分析=中位 / 難判断=上位）で運用
       │    本リポジトリには設計例として 3 体（codex-implementer / external-researcher /
       │    inventory-curator）とスキル 2 種（ui-flow / video-b）を収録
       │
       ├→ 安全層       hooks/*.py（PreToolUse 4 本 + SessionStart/End 2 本、計 6 本・453 行）
       │    破壊操作ブロック / 課金ゲート / 機密×外部送信ゲート / heredoc（シェルの複数行入力）
       │    事故の再発防止をコマンド実行前に検知しゲート
       │
       └→ 記憶層（本リポジトリには含まない）
            point-in-time な memory 66 件（恒久ルール 33 件を含む）。個人の実データのため非公開
```

## 設計判断（なぜそうしたか）

| # | 判断 | 理由 |
|---|---|---|
| 1 | **コスト別モデル振り分け** | 同じ作業を最上位モデルで回すと単価が 5〜10 倍になる。要約・探索は軽量モデル、設計・監査だけ上位モデルに限定し、各呼び出しのトークン数と概算コストを標準エラー出力に出して常時可視化している |
| 2 | **破壊的操作は hook と permissions.deny（許可設定の拒否リスト）で二重ブロック** | `rm -rf` 相当、DROP TABLE、WHERE 無し DELETE、シークレット直書きを正規表現で検知し exit 2 で止める。モデルの判断に頼らず基盤側で止める設計 |
| 3 | **「自律デフォルト＋金とリスクだけ人間ゲート」** | 通常操作は確認なしで実行し、実課金・青天井実行・機密を含む外部送信（AND 条件）のときだけ人間に確認を返す。確認を増やすと自律性が死に、減らすと事故が起きるため、その境界を明文化した |
| 4 | **機密は外部 API に出さない** | API キー・顧客データ・個人情報を含む処理はローカル LLM（大規模言語モデル、Ollama・GPU 推論）へ強制ルーティングする。中間業者（OpenRouter 等）は使わず直 API のみを使う |
| 5 | **記憶は point-in-time（記録時点のスナップショット）として扱う** | memory は書いた時点の事実であり現在の状態ではない。断定の根拠にせず、発言前に現状を再確認する運用ルールを基盤に組み込んでいる |
| 6 | **モデル ID の陳腐化に構造で対応** | 半年放置で全プロバイダが 1〜3 世代古くなることを実測した。自動追従エイリアスを使える社は使い、他は各社 `/v1/models` で実在 ID を定期確認する手順を運用化している |

## 運用実績

- 稼働期間: 2026-01 〜（継続中）
- 直 API 対応: 8 プロバイダ（Anthropic / Google / xAI / Zhipu / DeepSeek / Moonshot / OpenAI / ローカル Ollama）
- 実インシデント起点の改修: 2026-07-09、複数行ヒアドキュメントがツール呼び出しの構文を壊す事故が発生。原因を切り分け、恒久対策として `hooks/pretooluse-heredoc-gate.py` を新設。事故 → 恒久ルール化 → hook 化、の流れを 33 件の feedback memory として蓄積している
- サブエージェント構成は運用しながら 7 体 → 6 体へ整理
- この基盤の上で、本番稼働中の業務自動化システム（注文約 1,000 件を処理、職務経歴書参照）の開発・運用を行っている

## ディレクトリ案内

| パス | 内容 |
|---|---|
| `scripts/ask.py` | 振り分け層。8 社の直 API とローカル LLM を alias で呼び分ける（1,228 行） |
| `hooks/*.py` | 安全層。`pretooluse-guard.py`（破壊操作・シークレット直書きブロック）、`pretooluse-cost-gate.py`（課金操作の人間承認）、`pretooluse-external-send-gate.py`（機密×外部送信ゲート）、`pretooluse-heredoc-gate.py`（heredoc 事故の再発防止）、`session-start-logger.py` / `session-end-worklog.py`（セッションの開始・終了ログ） |
| `agents/*.md` | 委譲層。サブエージェントへの指示書（ゴール・制約・検証方法・報告フォーマットを明示） |
| `skills/*/SKILL.md` | 定型作業をスキル化した手順書 |
| `rules/*.md` | コーディング規約・セキュリティ・テスト方針・日本語応答時の注釈ルールなど、全プロジェクト共通の詳細ルール |
| `CLAUDE.md.example` | 全体指示のサンプル（個人運用色を除いた、設計思想として再利用可能な部分のみ） |

## 実物の読み方（まずここから）

採用担当がこのリポジトリを 2 分で判断するなら、次の 3 ファイルを推奨する。

1. **`hooks/pretooluse-heredoc-gate.py`** — 2026-07-09 の実インシデントから生まれた hook そのもの。原因切り分け → 恒久ルール化 → 基盤への実装、というサイクルが 1 ファイルで確認できる
2. **`agents/codex-implementer.md`** — サブエージェントへの委譲設計。役割分担・コスト構造・「ゴール・制約・検証方法・報告フォーマット」を明示した指示書の書き方が分かる
3. **`scripts/ask.py`** — 振り分け層の実装。1,228 行という規模感と、8 社の API 差異を吸収する設計が確認できる

## セットアップ

環境変数（値は各自のキーを設定。名前のみ）:

- `ANTHROPIC_API_KEY` / `OPENAI_API_KEY` / `GEMINI_API_KEY` / `XAI_API_KEY` / `DEEPSEEK_API_KEY` / `MOONSHOT_API_KEY` / `ZAI_API_KEY`
- ローカル推論を使う場合は Ollama（`127.0.0.1:11434`）が別途必要

Windows 注意点:

- Ollama 等ローカルサーバーへの接続は `localhost` ではなく `127.0.0.1` を明示すること（`localhost` 解決で数秒のスコールが発生するケースがある）
- コンソール既定エンコーディングが cp932 のため、hook の標準エラー出力は ASCII のみに統一している（日本語は文字化けし、Claude が自己修正する際の読み取りに失敗する）

## 免責

このリポジトリには実運用データ（memory ファイル群、コスト台帳、settings.json の実値）は一切含まれません。パス・金額・アカウント情報等のサンプル値はすべてプレースホルダです。
